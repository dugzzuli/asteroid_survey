# Active asteroids and main-belt comets

## Review question

Which mechanisms produce coma, tails, or mass loss on asteroidal orbits, and how can wide-field surveys identify such activity?

Mechanisms include sublimation, impact disruption, rotational instability, thermal fracture, and radiation-pressure or electrostatic processes. Core sources: Jewitt2012, JewittHsiehAgarwal2015, SnodgrassEtAl2017, and HsiehEtAl2015.
