# Core papers

## Selection rule

- **A — Landmark/foundational**: a method, survey, catalogue, data product, or reference model that a final review is expected to cite.
- **B — Representative**: a strong, well-scoped demonstration or comparison of an important approach.
- **C — Extended**: supporting literature for coverage, statistics, and specialised claims.
